# 决策记录: Swift 存量与提交格式化

状态: implemented

## 问题

已有格式工具和提交 Hook 覆盖 C 系列。用户于 2026-10-10 要求 Swift 同样处理，范围包含存量文件和后续提交，并继续遵守自然换行与可读性约定。

## 决策

使用 SwiftFormat 0.63.1，配置保存在 [.swiftformat](../../../../.swiftformat)。本机通过 Homebrew 安装，命令为 `brew install swiftformat`。SwiftFormat 与 Xcode 随附的 `swift-format` 是两个工具，本项目调用前者。工具行为与参数见 [SwiftFormat 官方说明](https://github.com/nicklockwood/SwiftFormat)及[规则说明](https://github.com/nicklockwood/SwiftFormat/blob/main/Rules.md)。

配置明确列出排版规则，统一四空格缩进、空格、空行、行尾及代码块结构，把同一行的多个分号语句展开。`--max-width none` 和 `--list-wrap-threshold none` 保持行宽自由；复杂代码按函数、条件和循环结构换行。导入顺序、访问级别、标识符、类型写法和调用形式保持原样，多行字符串内容保持原样。

继续使用 [scripts/format.sh](../../../../scripts/format.sh) 统一格式化和 `--check` 检查，按实际选中的文件寻找工具。默认范围包含 Git 已跟踪和未忽略的新 Swift 文件，也可指定文件或目录。第三方源码、Framework、上游补丁及构建目录按配置排除。

[pre-commit](../../../../.githooks/pre-commit) 增加 Swift 后缀，复用现有暂存文件选择与部分暂存保护。混合提交先检查两种工具是否齐全，再开始格式化；缺少工具时中止。具体提交行为见[提交前自动格式化](2026-10-10-提交前自动格式化.md)。

### 存量整理与验证

按用户本次明确要求整理现有自有 Swift 文件。对于主会话已有修改的文件，以当前内容为输入，写入前再次核对文件未改变；遇到并行变化则重新读取处理。格式化前后比较词法单元，忽略空白、注释正文和规则明确展开的分号，同时运行 Swift 编译器语法解析及重复格式化检查。

2026-10-10 在本机检查了 49 个 Swift 文件，其中 48 个发生排版变化。全部文件通过词法比较、`xcrun swiftc -frontend -parse -` 语法解析和重复格式化检查；再次格式化的输出保持一致。`NativeLinuxApp.swift` 与 `ProbeLogReader.swift` 原有的未提交修改保留在处理输入中，写入前未发现文件发生并行变化。各文件处理前后的 SHA-256 和修改状态记录在 [work/formatting/swift-2026-10-10.json](../../../../work/formatting/swift-2026-10-10.json)，该报告只保存校验结果。存量处理后，`bash scripts/format.sh --check '*.swift'` 检查通过。

`python3 scripts/test_precommit.py -v` 共 12 项测试通过，覆盖 C/Swift 混合提交、只处理暂存文件、部分暂存在任何格式写入前中止、工具缺失、特殊文件名、第三方排除、长行保持、重命名、删除及符号链接。测试在临时仓库执行，结束后清理。

### 复杂度审查

复用现有格式脚本、Git Hook 与测试结构，只增加 Swift 文件分支和工具配置。格式化由成熟工具执行，仓库不维护 Swift 源码转换器。现有工具入口仍负责文件选择，各语言配置负责对应规则与排除项。

## 曾考虑的替代方案

- 使用 Xcode 内置的 `swift-format`：其默认配置围绕固定 `lineLength` 排版，选择能明确关闭行宽折行的 SwiftFormat。
- 使用 SwiftFormat 默认全部规则：会涉及类型简写、导入顺序等代码改写，本次明确选择排版规则。
- 仅增加后续提交检查：用户要求同时整理存量，现有自有 Swift 源码一起处理。
- 为 Swift 另建独立 Hook：文件范围与部分暂存保护会重复，沿用同一个提交入口。

## 影响

存量与新提交采用同一份 Swift 排版配置。克隆项目后安装 clang-format、SwiftFormat 并启用现有 Hook，即可使用统一命令。本次排版验证覆盖格式、词法与语法；Android 功能和真机验证继续由主会话按阶段安排。
